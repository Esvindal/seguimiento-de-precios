Seguimiento de precios
sin servidor.

Un workflow de GitHub Actions corre este scraper cada seis horas, guarda el historial en data/precios.json y commitea solo si algo cambió. Esta página lee ese mismo archivo. Cero backend, cero costo.

Fuente de práctica: los datos vienen de books.toscrape.com, un sitio publicado expresamente para aprender scraping. Los precios son ficticios.

Cómo funciona

  1. Programado. cron: 17 */6 * * * dispara el workflow cada 6 horas (también manual con workflow_dispatch).
  2. Respetuoso. El scraper se identifica con su propio User-Agent, espera entre pedidos y verifica robots.txt antes de descargar.
  3. Idempotente. Cada producto acumula puntos {ts, precio, disponible} solo cuando el valor cambió: el repo no se llena de commits vacíos.
  4. Publicado. Los datos se copian a docs/data/ y GitHub Pages sirve esta página y las alertas ya evaluadas.
